# Landing Page Image Replacement Guide

IMAGE REPLACEMENT

Hero:
- `src/assets/hero.png`

Teacher 1:
- `src/assets/landing-teacher-1.svg`

Teacher 2:
- `src/assets/landing-teacher-2.svg`

To replace an image:
1. Put the new image at the same path.
2. Keep the same filename.
3. Refresh the application.

The landing page uses local assets imported from `src/mocks/landingMockData.js`, so replacing the file keeps the page logic unchanged.
