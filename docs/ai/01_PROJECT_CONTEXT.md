# PROJECT CONTEXT

## Project Name

رياضياتي (Riyadiaty)

---

# Project Type

Enterprise Multi-Tenant Learning Management System (LMS)

This is NOT a landing page.

This is NOT an admin template.

This is a complete production-ready educational platform that supports multiple instructors, multiple roles, and multiple educational stages.

The platform must feel like a premium SaaS product.

---

# Primary Goal

Deliver the best Arabic educational experience through a modern, elegant and premium interface while keeping the application extremely easy to use.

The UI should communicate:

- Trust
- Simplicity
- Professionalism
- Academic Excellence
- Calmness
- Premium Quality

The user should feel that every screen belongs to one carefully designed system.

---

# Target Users

Student

Parent

Instructor

Assistant

Admin

Each role has its own dashboard.

All dashboards must still follow one unified design language.

---

# Platform Philosophy

The platform is built around one principle:

"Content comes first."

Decorations never compete with educational content.

Every visual decision should improve readability.

---

# UI Philosophy

The UI must be

Minimal

Premium

Modern

Elegant

Calm

Readable

RTL First

Touch Friendly

Responsive

Accessible

Professional

Every page should look like it belongs to the same design system.

---

# Design Inspiration

The design language is inspired by

Apple Human Interface

Linear

Notion

Raycast

Stripe

Modern Dashboard Systems

Arabic Educational Platforms

DO NOT copy these products.

Use them only as inspiration.

---

# Visual Identity

The visual identity relies on

Soft rounded corners

Large spacing

Soft shadows

Warm colors

Minimal borders

Glass effects only when appropriate

Smooth transitions

No visual clutter

No heavy gradients

No unnecessary animations

---

# Color Philosophy

Yellow represents actions.

Green represents learning.

Red represents critical alerts.

Blue represents information.

Gray represents neutral surfaces.

Colors should never be decorative.

Every color must communicate meaning.

---

# Typography Philosophy

Arabic readability has higher priority than decoration.

Large headings.

Comfortable paragraph spacing.

Readable cards.

Readable tables.

Readable forms.

Never reduce readability for aesthetics.

---

# Component Philosophy

Every UI element must reuse existing components whenever possible.

Never duplicate components.

Never recreate existing UI.

Always extend existing components.

---

# Layout Philosophy

Layouts must remain consistent across the application.

Navigation should never jump.

Spacing must feel predictable.

Cards must align perfectly.

Sections must breathe.

---

# Motion Philosophy

Motion exists only to improve usability.

Animations should never distract.

Prefer

Fade

Scale

Translate

Opacity

Avoid dramatic effects.

---

# Responsive Philosophy

Desktop First

Tablet Optimized

Mobile Friendly

No broken layouts.

No horizontal scrolling.

Navigation must adapt gracefully.

---

# Accessibility

Keyboard Friendly

Visible Focus

High Contrast

Proper Labels

Readable Text

Large Click Areas

Accessible Forms

---

# Code Philosophy

Readable code is more important than clever code.

Prefer composition over duplication.

Prefer reusable components.

Prefer design tokens.

Never hardcode values that already exist inside the design system.

---

# AI Mission

The AI is NOT here to redesign the platform.

The AI exists to improve the interface while preserving architecture.

The AI must think like a Senior Frontend Engineer joining an existing enterprise project.

Before making any change the AI must understand:

Existing components

Existing tokens

Existing layouts

Existing patterns

Existing architecture

Only after understanding these may the AI modify the UI.
