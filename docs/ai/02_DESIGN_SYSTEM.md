# DESIGN SYSTEM
Version: 1.0

---

# Design Principle

The platform should feel like a premium educational product.

Not colorful.

Not playful.

Not corporate.

The experience should feel calm, clean, elegant and trustworthy.

Every page must belong to one visual language.

---

# Core Design Values

Premium

Minimal

Academic

Warm

Elegant

Readable

RTL Native

Accessible

Consistent

Predictable

---

# Visual Hierarchy

The user's eye should always move in this order:

1. Page Title
2. Primary Action
3. Important Information
4. Supporting Content
5. Secondary Actions

Never compete with the content.

Primary

Golden Yellow

Primary CTA

Progress

Success

Warnings

Information

Soft Blue

---

# Surface Hierarchy

Surface 0

Page Background

Surface 1

Cards

Surface 2

Nested Cards

Surface 3

Floating Elements

Never place cards directly on identical surfaces.

---

# Borders

Borders should be subtle.

Use borders only when necessary.

Never use dark borders.

Prefer separation through spacing.

---

# Cards

Cards are the core building block.

Every card should have:

Large Radius

Large Padding

Soft Shadow

Clear Header

Readable Body

Enough White Space

Never overcrowd cards.

---

# Buttons

Buttons should communicate importance.

Primary

Filled

Secondary

Outlined

Ghost

Transparent

Danger

Red

Never invent new button styles.

Always reuse Button component.

---

# Forms

Large Inputs

Comfortable Height

Visible Labels

Readable Placeholders

Large Click Targets

Proper Validation

Never create custom inputs.

Reuse Input component.

# RTL

RTL is the default.

Never convert layouts to LTR.

Spacing

Icons

Navigation

Animations

must all respect RTL.

---

# Dashboard Philosophy

Dashboard is not a landing page.

Dashboard must prioritize:

Information

Statistics

Actions

Progress

Alerts

Everything else is secondary.

---

# Landing Pages

Landing pages may contain

Hero

Illustrations

Marketing Sections

Teacher Cards

Testimonials

Dashboard pages must not.

---

# Density

Prefer breathing room.

Large spacing.

Avoid crowded interfaces.

Users study for long hours.

Eye comfort is a priority.

---

# Reuse Policy

If a component already exists,

reuse it.

Never recreate it.

Never duplicate styling.

Never duplicate layout.

Never duplicate behavior.
